# Brand assets

- `sparklesnap-watermark-v1-web.webp` — the in-app top-bar logo, copied unchanged from the SparkleSnap brand library.
- `myuuel-logo.png` — earlier Myuuel sticker logotype (now unused in the app; kept as the icon source). Upper-left full-body drawing cropped from
  Myuuel's idle sprite sheet (cell 0, bbox 233,148–535,704),
  with a light warm grade, a cream sticker outline and a soft gold glow; 512 px tall, palette-compressed.
- `icon.ico` / `icon-256.png` — launcher, shortcut and window icon: the same sticker on a plum rounded square with a gold ring.

The source sprite file is unchanged.
